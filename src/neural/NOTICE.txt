The original shader's notice specifies GPL version 3 or later. The upstream
repository additionally supplies an LGPL version 3 license. Both license texts
are included; the launcher's MIT notice does not replace these upstream notices.

The original shader is preserved verbatim. scripts/prepare-neural.cjs adapts its
six passes to an independently loaded Direct3D 11 shader interface: constant
buffer and texture bindings, sampler declarations, dispatch wrappers, and a
simple bijective 8x8 thread mapping. Learned weights and network math are kept.
Generated passes.json is an ordinary replaceable local resource, not embedded
in the launcher executable. No proprietary Magpie implementation is included.
All launcher adapter/build sources are public at:
https://github.com/Daniel-Prizer/dungeon-blitz-launcher
