# Experimental widescreen (0.11.0, minor)

Enable Settings > Display > Experimental 16:9. It starts off and saves your explicit choice. The world-view frame, including the original HUD-height allowance, changes from 1152 x 768 to 1365 1/3 x 768. The outer decorative border adds 31 logical pixels on each side, so its measured outer aspect is slightly different from 16:9. World sprites retain uniform scale; this does not stretch a screenshot or reveal more vertical world.

Login/title/character artwork and multi-Game connection/scene handovers retain the original layout. During STATE_PLAY the existing camera uses the wider logical extent; the original resize/cache invalidation allocates matching raster surfaces. Bottom HUD/chat/quest groups and dialogs remain centered at original dimensions, independent top controls anchor toward the left/right, and a muted gray vector border fills the widened frame and bottom backing area without accepting input. No artwork replacement, camera-height change, network edit or animation speed change is made.

The October 10 client's transition allocator had replaced the original scaled camera dimensions with a fixed 2048 x 1152 bitmap. At ordinary 1080p/1440p this mismatches the launcher's raster surface and can spill into, or leave seams beside, the gray margins. The reviewed correction restores the original allocator byte-for-byte. The isolated regression calls the actual Game.method_1947, reproduces the bad allocation in a baseline fixture, then checks matching dimensions after the correction. The original and corrected method bodies are full-hash checked, and the 38-byte substitution preserves branch/exception offsets.

Validation uses a guarded inactive Windows desktop: actual Flash layout/allocator/input methods, synthetic world and HUD roots at 1080p/1440p, detail changes, repeated offset stability, left/center/right native mouse coordinates, frame click-through, toggling off and returning to menus. The real live title screen also renders with the setting enabled while retaining original artwork. Captures are of test WebContents only; no input desktop capture, desktop switching, clipboard access, login or ClipCursor call is made.

This is not validated against every live authenticated HUD, dungeon transition or encounter. Some maps may reveal blank/unfinished scenery, camera clamps may be designed for the original width, and complex fixed-width overlays may need additional positioning. Use the original layout if an overlay is misplaced. The preservation server does not advertise support for this modification; no claim of official compatibility, FPS gain or altered gameplay rules is made.
