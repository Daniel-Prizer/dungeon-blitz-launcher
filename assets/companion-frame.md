# Companion ornament

Generated as a transparent bitmap with the imagegen skill, using the supplied public 2008 Dungeon Blitz HUD excerpt as a style reference. No private account screenshot was used.

Direction: two square companion slots, old Flash game artwork, restrained warm gold edging and small leaf/scroll shoulders; charcoal wells, compact silhouette, no lettering, glow, glossy metal or new UI controls. Native pet/mount artwork and key labels remain the game's own controls above this passive decoration.

The build embeds a bounded static ARGB surface through EmbedCompanionArt.java. Production uses no external image loader, executable asset or captured game frame. The ornament is distinct from the untouched ability recess and accepts no input.
